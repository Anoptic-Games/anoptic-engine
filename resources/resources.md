# Resources Directory

Built-in engine resources.


## Directory Structure

```
resources/
├── shaders/          # engine shaders
├── textures/         # fallback textures
├── fonts/            # fonts
├── audio/            # default SFX / music
└── scripts/          # default AI / game logic
```


## Usage

Fallbacks/defaults when a game provides none.

Game-specific resources live with the game, not here.
